# PAR1AH-KEYS

Android keyboards by PAR1AHWARE.

## Keys Custom — 0.4.0-alpha2 / build 8

**Testing prerelease:** [APK, AAB and checksums](https://github.com/par1ahware/PAR1AH-KEYS/releases/tag/keys-custom-0.4.0-alpha2-build8) · [website and installation](https://www.par1ahware.com/keys-custom).

The best completed-swipe match now appears immediately in your actual text field. Tap another ranked suggestion to replace it, delete to retry, or keep typing. Pausing leaves the provisional word visible and correctable. The short theme-colored trail is thicker and darker.

Preserves the 91,676-word offline English vocabulary, stacked Studio categories, settings search, key/row deletion, Undo/Redo and saved custom layouts. The exact signed candidate passed 42 targeted Samsung phone tests, including external native and WebView editors. Full messaging/browser, fresh human device accuracy, physical tablet and full compatibility/performance acceptance remain pending. One narrow-layout hello/help ranking fixture remains open; reference-style layouts are provisional.

Install the app-signed APK as an update to preserve data. The upload-signed AAB is for distribution workflows and does not install directly. Keys Custom (`com.par1ahware.keys.custom`) is separate from Keys; settings do not transfer automatically. This is a testing prerelease, not complete production acceptance.
